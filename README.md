# 👋 Hola, soy Felix

Desarrollador web con enfoque principal en **Frontend con Angular**, pero con experiencia completa en **Backend, bases de datos y servidores**.  
Puedo construir **aplicaciones web completas** desde la interfaz hasta el despliegue.

---

## 🧠 Qué hago

### 🎨 Frontend
- Desarrollo de aplicaciones completas con **Angular**
- Componentes reutilizables
- Formularios reactivos y validaciones
- Consumo de APIs REST
- Manejo de estado y lógica con RxJS
- Diseño responsive y adaptable

### ⚙️ Backend
- Desarrollo de APIs con **NestJS**
- Autenticación (JWT)
- CRUDs completos
- Validaciones, guards, interceptors
- Documentación con Swagger

### 🗄️ Base de datos
- **PostgreSQL**
- Modelado de datos
- Relaciones, índices y consultas
- Integración con ORM (TypeORM / Prisma)

### 🌐 Servidores y despliegue
- Hosting en **cPanel / WHM**
- Configuración de dominios
- Despliegue de aplicaciones web
- Manejo de entornos y builds

### 🖥️ Páginas web
- Landing pages
- Sitios corporativos
- Paneles administrativos
- Sistemas web a medida
